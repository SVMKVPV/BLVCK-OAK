Website records are already available. Connect your GA4 property to add Google's acquisition, engagement, key event, ecommerce and realtime reports.

Connection steps for your site administrator
  1. Choose the BLVCK OAK GA4 property and enable the Google Analytics Data API in your Google Cloud project.
  2. Authorize read-only Analytics access for an account with access to that property. Obtain an OAuth refresh token using https://www.googleapis.com/auth/analytics.readonly.
  3. In Netlify, set GA4_PROPERTY_ID, GA4_CLIENT_ID, GA4_CLIENT_SECRET and GA4_REFRESH_TOKEN as server-side variables with Functions access, then redeploy.
  4. Use the numeric property ID, not the G- measurement ID. Keep secrets out of frontend code and chat.

Connecting reports does not install a Google tag or import past visits. The GA4 property must already collect the events you want to report.
