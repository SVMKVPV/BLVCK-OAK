04 / TRUST ARCHITECTURE

Good fintech starts with what the product refuses to fake.

BLVCK OAK PAY uses the site's existing passwordless account session, HttpOnly cookies, same-origin checks and server-side data storage. Real transfers, PayID issuance, KYC/AML decisions and rewards redemptions are held behind provider activation rather than represented as live when they are not.

HttpOnly session access Server-side account isolation CSRF-protected changes No card or bank credentials stored in browser code Payment-provider activation gate KYC / AML onboarding slot
